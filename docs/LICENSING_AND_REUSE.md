# Licensing and Reuse Decision

**Status: owner decision required; release-blocking.**

Raw SQL Vault is being prepared for public consumption. The project must not imply that users can copy, modify, redistribute, or sell the contents until an explicit license is selected and added. Public GitHub visibility is not itself an open-source license.

Decide whether one license covers all content or separate terms apply to SQL/code, prose and curriculum, diagrams/media, third-party snippets, and datasets. A license cannot grant rights the owner does not hold.

Options to evaluate:
- **MIT:** short permissive software license; requires preservation of notices.
- **Apache-2.0:** permissive software license with explicit patent provisions and additional notices.
- **GPL-family:** copyleft obligations may fit a reciprocal-sharing goal.
- **CC BY 4.0:** often considered for documentation, not software code.
- **All rights reserved/no license:** grants no general reuse permission and does not meet an open-reuse goal.

This list is informational, not legal advice or a license choice on behalf of the owner. Consider contributions, commercial goals, attribution, patent concerns, and third-party material.

Decision checklist:
- [ ] Owner approves license(s).
- [ ] Ownership and provenance of included content confirmed.
- [ ] Full license text and SPDX identifier(s) added.
- [ ] Covered files/materials explained.
- [ ] Contribution terms match the license.
- [ ] Third-party notices and dataset terms checked.
- [ ] README and package metadata updated.
- [ ] Decision re-reviewed before visibility changes.

Until resolved, do not describe the project as open source or imply redistribution permission. Keep visibility private unless the owner explicitly accepts publishing unlicensed material. Track [issue #72](https://github.com/PerezChris99/raw-sql-vault/issues/72).
